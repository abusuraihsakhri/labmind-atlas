    03 / RESPONSIBLE DEPLOYMENT

    What this demonstration does—and does not—prove

    Available in this browser demo

    • Deterministic TAT risk indicators
    • Synthetic event injection and specimen sign-out
    • OBSERVE / SUGGEST staging
    • Human approval, dismissal and alert acknowledgement
    • Temporary audit timeline with CSV export

    Requires the real backend and validation

    • Authenticated users, RBAC, and durable logs
    • HL7 ingestion, PHI handling and token resolution
    • Redis, PostgreSQL and worker orchestration
    • Model inference, communications and clinical thresholds
    • Laboratory-specific prospective validation and governance

    Not a medical device, diagnostic aid, real alerting service, or validated clinical decision-support tool. Do not enter patient information. Review the build specification and the source repository for the implementation and its limitations.
